## Featured project

### [ConfigSentry](https://github.com/Piriyangan/ConfigSentry)

An offline security auditor for switch, router and firewall configurations. Upload a config and it shows each weak setting, the exact line, and the commands to fix it.

- 189 checks across 10 platforms: Cisco IOS / IOS-XE, NX-OS, ASA, FortiGate, Palo Alto, Check Point, Juniper, Huawei, MikroTik and Sophos
- Local web app and command line, HTML and JSON reports, secrets masked by default
- Runs on Windows, Linux and macOS, and never connects to your devices
